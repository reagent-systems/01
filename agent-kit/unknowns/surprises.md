# Surprises

Append only. One entry per surprise, newest last. Written the moment it happens, by a human or an agent.
The weekly loop turns each entry into a register item and records the item ID here.

Entry shape:

```
## YYYY-MM-DD — <who> — <one line>
Expected: <what we thought>
Happened: <what occurred>
Evidence: <link, file, or issue number>
Register: <ITEM-ID or "to convert">
```
