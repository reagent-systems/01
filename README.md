# 01

Design hardware without capital. A designer publishes a design, buyers join a waitlist with a saved card, the price falls as the count rises, and one button starts every shop in the chain.

The spec is `agent-kit/unknowns/evidence/handoff-spec.md`. The process for agents and people is `agent-kit/ROUTING.md`.

```sh
pnpm install
pnpm verify          # lint, build, test, register lint, kit gate
pnpm unknowns:report # what we do not know yet
```

Feedback goes in as a GitHub issue (feedback, surprise, unknown, bug, roadmap). See `agent-kit/ROUTINES.md`.
